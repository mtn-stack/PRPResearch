Private Residential Planning Research

This repository is an exploratory personal research project using publicly available data open data APIs.

The project focuses on retrieving and analysing planning decision records, with a particular interest in applications that may relate to residential use, housing, apartments, landed properties, and similar development types.

## Purpose

This is not a commercial product or public-facing application. It is a personal learning and research project.

## Research Focus

The initial research focus is on residential-related planning decision records, including records that may mention:

- residential
- dwelling
- flat
- apartment
- condominium
- landed property
- terrace house
- semi-detached house
- bungalow
- housing

The filtering approach is currently keyword-based and intended for exploratory analysis only. It may be refined as I better understand the structure and fields of the API response.

This repository does not contain confidential data, private data, API keys, or authentication tokens.

## Project Status

This is an early-stage exploratory project.
